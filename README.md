# Micro Racing

3D аркадная гоночная игра на Python с Ursina Engine.

## Установка

```bash
python -m venv .venv
```

Windows:
```powershell
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

## Управление

### Игрок 1
- W / стрелка вверх — газ
- S / стрелка вниз — тормоз
- A / D — поворот
- Space — нитро

### Игрок 2 (локальный режим)
- I — газ
- K — тормоз
- J / L — поворот
- Right Shift — нитро

### Общее
- Esc — пауза / продолжить
- Enter — вернуться в меню после гонки

## Режимы
- RACE — гонка против ботов
- LOCAL MULTIPLAYER — локальная игра на двоих
- GARAGE — покупка и выбор машин
- MAP — переключение карт

Прогресс сохраняется в `data/save.json`.

сложные модели машин, звук и полноценные AI-траектории можно добавить
